# GeoSoilMLOps v1.0.0

First archived release of **GeoSoilMLOps** associated with the manuscript:

*Machine Learning Prediction of Soil Activity Using Geotechnical and Geological Features: Location-Aware Assessment of Model Generalization*

## Included

- GTFS: geotechnical-only MLOps workflow
- GLFS: geology-enhanced MLOps workflow
- YAML-driven experiment configuration
- Configurable regression and classification
- Optional location/group-aware validation
- Nested cross-validation and independent holdout evaluation
- Hyperparameter optimization
- Learning-curve analysis
- Permutation-sensitivity / permutation-importance analysis
- Automated model evaluation and ranking
- Interactive prediction utilities
- PDF, Markdown, JSON, and CSV research summaries
- Reproducibility metadata and experiment profiles

## Data availability

The original research dataset is **not included** because of data-sharing restrictions. Any synthetic or sanitized example dataset included with this release is supplied only to demonstrate the expected input structure and workflow and must not be interpreted as the original research dataset.
