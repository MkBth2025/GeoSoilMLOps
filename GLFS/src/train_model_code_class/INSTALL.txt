This version fixes:
1. Missing validation metric keys in _flatten_results().
2. XGBoost/scikit-learn scorer-tag compatibility by using prediction-based callables.
3. Optional learning-curve failures now skip cleanly instead of breaking training.
4. XGBoost nested parallelism by using n_jobs=1 inside XGBClassifier.
5. Test metrics remain isolated from model selection.

Recommended before rerunning in PowerShell:
  Get-ChildItem -Recurse -Directory -Filter __pycache__ | Remove-Item -Recurse -Force

Run from project root:
  python src/trainclass.py --data data_Ac/processed --models_dir models_Ac --reports_dir reports_Ac --params params.yaml
